# 足球比赛分析与下注流程

## 两条基本规则

1. **预测不看赔率。** 胜平负概率只能来自球队、球员和比赛本身的信息，不参考任何赔率、盘口或预测网站给出的胜率，否则预测会被市场价格锚定。
2. **下注才看 Kalshi。** 概率定下来以后，再拿去和 Kalshi 的价格比较。只买扣除手续费后期望值为正、并且超过最低门槛的方向。

## 时间线

| 时间 | 做什么 |
|---|---|
| 赛前一天 | 按下面的「七步法」和「补充检查」得出初版概率、最可能比分和倾向，**先写进 `predictions_log.csv`，之后才能看 Kalshi 价格**，避免被市场锚定 |
| 开球前约1小时（首发公布后） | 必须更新一次：阵型、首发中锋、临时拼凑的后防、伤愈复出的球员是否首发 |
| 更新后 | 查看 Kalshi 实时价格，运行 `scripts/football_ev.py ev`，按下注规则决定买不买 |
| 赛后 | 把结果写进 `predictions_log.csv`，运行 `scripts/football_ev.py score` 跟踪累计准确度 |

## 七步法（来源：博扬）

1. **白面（身价、排名、过往地位）。** 权重低，只用来建立第一印象。
2. **主客场。** 比较重要。看主队本季的主场战绩和客队本季的客场战绩；上赛季的数据要打折，换帅或核心离队时尤其如此。
3. **交锋历史。** 只在时间窗口内才有意义：
   - 国家队看一个大赛周期，也就是约4年；
   - 五大联赛这类比赛频繁的联赛，最多看两个赛季，更早的不看。
4. **伤病。**
   - 只看最近约一个月内新出现的伤病。更早的伤病已经反映在球队的近期战绩里，能调整的都已经调整过了。
   - 不认识的球员也没关系：看他本季出场几次、首发几次，就能判断是不是主力。
   - 最后按锋线、中场、后防分别总结受影响的程度。
5. **近期状态。** 只看同一项赛事。
   - 每个结果都要放到对手强度里看：输给前三和输给降级区球队，性质完全不同。
   - 还要看对手**当时**的状态，而不只是排名。比如利物浦开局慢、赫尔城先强后弱，碰上的时机会影响结果的含金量。
   - 刚结束连败的球队，要特别留意它的反弹势头。
   - **对手强度是这一步的核心，不能只看战绩。** 每支球队最近5到6场正式比赛都要列成表：
     - 对手、主客场、比分；
     - 对手现在的排名或实力档次（能找到 Opta 实力排名或俱乐部 Elo 就用，找不到就用联赛排名加联赛水平）；
     - 对手当时的状态；
     - 这个结果按对手折算后说明了什么。
   - **跨联赛要明确比较。** 比如在奥地利联赛4-0赢垫底球队，含金量远低于在意甲客场1-1。
   - **反过来也一样。** 一支球队在强联赛里成绩差，面对弱得多的对手时不一定也差。2026-10-14 斯图加特在德甲低迷，但0-3客胜了斯洛凡。
6. **进失球。** 和对手、比赛情境一起看。
   - 比如0-5输给布莱顿，第53分钟被罚下一人时比分是0-2，5个丢球里有3个是少一人时丢的。
   - 被防守型球队灌进很多球，比输给强队更值得警惕。
7. **新闻。** 包括经营状况、更衣室氛围、主帅帅位、球员心理状态等。这部分很难量化，只能凭经验判断，但要写下来。

## 补充检查（来自2026-10-12复盘）

- **停赛要单独列出。** 例如考文垂主力前锋阿沃尼伊停赛，对锋线的影响比任何伤病都大。
- **看顶替的人。** 主力缺阵时，替代者是谁、状态如何，往往比缺阵本身更关键。那场比赛被我们看作短板的19岁前锋谢里夫，最后当选全场最佳。
- **用 xG 和射门区分运气和实力。** 积分榜和比分会骗人，要看过程数据：
  - 纽卡5场拿8分，但每一场的 xG 都输给对手；
  - 考文垂4-1赢球，但纽卡射门19比9、xG也更高，比分夸大了差距。
- **比分分布要给大比分留空间。**
  - 当晚9场平均每场3.7球，5场进了4球或更多，而我们的首选比分大多是1-0或1-1。
  - 遇到防线正在崩的球队或垫底球队，要单独评估"先丢球之后整体崩盘"的风险，给2球以上的分差留出概率。
- **小样本指标和旧数据要降权。** 例如门将的扑救超预期数据、上赛季的客场战绩、只有8场样本的客场 xG，都不能当成核心论据。
- **调整要和证据相称。** 已经识别出明确的反向证据时，不能只改一两个百分点（法马利康对阿尔维尔卡那场就是这个错误）。如果几条证据指向同一方向，就要敢于拉开概率，不要习惯性地往三分天下收缩。
- **边际缩水或数据可疑就放弃，不要缩小仓位继续下注。** 深入分析后边际明显变小，或者关键数据来源对不上，就直接不下。2026-10-13 莱比锡胜-No 那单：分析发现莱比锡主场很强，PSV 的数据又不可靠，我们却只是把仓位降小，结果0-1输了。
- **不要因为缺一两个人就去赌状态极好的大热门赢不了。** 阵容深、状态好的强队对伤停不敏感。2026-10-13 巴萨缺拉菲尼亚和德容，照样4-1赢了加拉塔萨雷。
- **优先选和我们已知偏差方向相反的下注。** 我们的模型容易低估热门、低估进球。所以"双方都进球-Yes"这类和偏差方向相反的正EV，比"热门赢不了"这类更可信。

## 补充检查（来自2026-10-14复盘）

- **反热门或押小球的下注，在"强队加成"情景下也要达到 +3¢。**
  - "强队加成"情景是把热门的预期进球乘1.15、冷门乘0.90。
  - 13日和14日两晚，赌热门赢不了或赢不多的下注1胜4负：拜仁让球 No 赢；巴萨让球 No、莱比锡胜 No、斯图加特让球 No、费内巴切胜 Yes 都输。
  - 和我们偏差方向相反的下注2胜0负：国米双方进球 Yes、矿工胜 Yes。
  - 14日四笔里，只有矿工在这个情景下还能达到 +3¢（+11.8¢），它也是唯一赢的那笔。
- **总进球要上调。**
  - 前27场平均每场4.1球，14日一晚是5.1球，而我们给的预期进球每场只有约3.1球。
  - 定预期进球时，要和市场隐含的总进球对比；比市场低就要写出理由。
  - 押"赢不了2球""小球"这类方向时，要求我们的总进球不低于市场。
- **3场左右的主场或客场战绩是小样本，不能压过整体状态和阵容实力。**
  - 维拉"主场3场不胜"，对手是阿森纳、森林和布伦特福德；同期它5场进12球，欧冠首轮客场还赢了布鲁日。
  - 我们给维拉47%，市场60%，结果维拉6-0。
- **"对手强度"要双向折算。**
  - 斯图加特本季在德甲表现低迷，不等于它面对斯洛伐克球队也会低迷。
  - 两季窗口边缘的交锋（2025年斯图加特 xG 3.46）虽然权重低，但如果它反映的档次差距今天依然存在，就不能忽略。
  - 结果斯图加特0-3赢球，斯洛凡一脚没进。

## 补充检查（来自2026-10-15复盘）

- **"我们低估热门"的修正，只用在状态好、阵容深的热门身上。**
  - 马赛近7场5负，后腰核心霍伊别尔和中卫科内柳斯缺阵，赛报显示锋线是莫佩，主力前锋古伊里大概率没有首发。

  - 证据向下时，要把 Elo 基准往下调，不能再用偏差修正往上抬。
- **按 Elo 逐场折算对手强度有效，继续用。**
  - 这一晚12场 Brier 0.444，市场是0.449，是我们第一次比市场准。

  - 本菲卡、伯恩茅斯、亚特兰大、桑德兰这几场，市场都比我们准。
  - 39场累计，热门实际赢25场，按我们的概率只预期19.65场。
  - 市场给热门70%以上时，没有具体证据，我们的概率就不要比市场低5个百分点以上。
  - 10月14日定的两条规则（反热门要在强队加成情景下也过 +3¢；总进球不能低于市场）挡掉了本菲卡和伯恩茅斯让1.5球 No 两笔。结果本菲卡4-1、伯恩茅斯3-0，两笔本来都会输。
- **首发检查要执行。** 马赛那场"古伊里不首发就减半"这一条，正好对应了输球的原因。
- **过程对、结果差，不要因此改模型。** 圣吉罗斯 xG 2.01比0.59压制对手，最后1-1。

## 下注规则（默认值，可以调整）

- **手续费（以 Kalshi 官方文档为准）。**
  - 吃单（taker）的模型手续费是 `0.07 × 份数 × 价格 × (1 − 价格) × fee_multiplier`。
  - kalshi.com 直接开户的账户，扣费后余额对齐到 $0.0001；通过经纪商（FCM）结算的账户对齐到 $0.01（CLI 加 `--fcm`）。同一笔订单分多次成交时，多收的零头会通过累计返还。
  - 挂单（maker）是否收费取决于系列的 `fee_type`，这个值可以通过 `GET /series/{ticker}` 查到：
    - `quadratic`：挂单不收费，例如巴甲、阿甲、葡超；
    - `quadratic_with_maker_fees`：挂单按 0.0175 收费，例如英超 `KXEPLGAME`、西甲、意甲。
  - 用 `--maker` 时，`--prices` 必须填你自己挂的限价；按当前卖价下单会直接成交，按吃单计费。
- **价格一律用卖价（ask），也就是实际要付的价格。**
  - Yes 卖价就是 Yes 当前的卖价。
  - No 卖价等于 100 − Yes 买价，不是 100 − Yes 卖价；两者至少差一个最小报价单位。没有填 `--no-prices` 时，工具不评估 No 合约。
- **最低边际。** 扣费后每份合约的 EV 至少 +3¢ 才下注。我们的概率误差不小：首批9场的 Brier 分数是0.588，三项都给1/3的基准是0.667，只好一点。所以小于3¢的边际视为噪音。
- **仓位。** 用 1/4 Kelly，单场最多投入资金的 2%。手续费和边际都按实际下单份数重新计算；不够买1份就不下注。
- **一场只下一个方向。**
  - 同一场比赛的各个合约是相关的。比如"主胜-Yes"和"客胜-No"在主队赢球时会一起赢，同时买等于加倍押同一个结果。
  - 候选方向按"在实际下注金额下，资金的期望对数增长"排序，不按每份合约的 EV 排序，因为贵的合约每份 EV 大，但每投入1美元的回报低。

```bash
# 例：考文垂 vs 纽卡，我们的概率是 35/31/34。
# Kalshi（KXEPLGAME-26OCT12COVNEW）开球前1小时的报价：Yes 卖价 27/27/48¢，Yes 买价 26/26/47¢，所以 No 卖价是 74/74/53¢。
python scripts/football_ev.py ev --probs 0.35 0.31 0.34 --prices 27 27 48 --no-prices 74 74 53 --bankroll 1000
# 输出：考文垂胜-Yes 每份 EV +6.6¢，买70份共 $19.87（资金的2%）；平局-Yes 只有 +2.6¢，低于门槛。
python scripts/football_ev.py score football/predictions_log.csv
```

## 记录表字段（`predictions_log.csv`）

| 字段 | 说明 |
|---|---|
| `date` | 比赛日期 |

| `kalshi_no_home`, `kalshi_no_draw`, `kalshi_no_away` | 决策时 Kalshi 的 No 卖价（100 − Yes 买价），单位为分；没有就留空 |

| `outcome` | `home`、`draw` 或 `away`；还没比赛就留空 |
| `notes` | 备注 |
